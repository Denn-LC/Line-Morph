# Data

Data used for the Line-Morph project

## Catalogues

### Fairlamb et al. (2015)

`fairlamb_2015_raw.tsv` is the original catalogue downloaded from VizieR for the 91-star Herbig Ae/Be sample from Fairlamb et al (2015)

`fairlamb_2015.csv` is a cleaned version used for querying the ESO Science Portal, the header is removed and it is converted to a csv


## Spectra

Spectral data (does not yet exist) downloaded from the ESO Science Archive are not stored in this repository as they are very large, all are ignored in the .gitignore
